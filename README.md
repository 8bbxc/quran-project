# quran-project

> **منصة متشابهات القرآن الكريم** — منصة ويب تفاعلية متطورة متخصصة في تيسير حفظ وتثبيت وضبط متشابهات القرآن الكريم لحُفّاظ كتاب الله ومعلمي الحلقات القرآنية وفق المنهجية السلفية الصحيحة والرسم العثماني التام.

---

## 🌟 الميزات الرئيسية (Key Features)

1. **الرسم العثماني التام والدقة المطلقة:**
   - نص قرآني مشكول ومضبوط بنسبة 100% بالرسم العثماني برواية حفص عن عاصم، بمطابقة تامة مع مصحف مجمع الملك فهد لطباعة المصحف الشريف، ومصحف جامعة الملك سعود الإلكتروني (KSU Quran)، وتطبيق ترتيل.

2. **التسميع الصوتي والذكاء الاصطناعي (Voice Testing):**
   - تسميع صوتي مباشر عبر الميكروفون مع خوارزمية ذكية لاكتشاف اللبس بالآيات المقابلة والتنبيه الفوري.

3. **عرض المصحف الشريف بالصفحات (604 صفحات):**
   - إطار مذهب مستوحى من مصحف المدينة مع تظليل الآيات المتشابهة في سياق الصفحة ودرج مقارنة فوري.

4. **خريطة المتشابهات الذهنية التفاعلية (Mind Map Graph):**
   - شبكة رسومية SVG تفاعلية بنظام توزيع شعاعي متوازن يربط أصل المتشابه بالسورة ورقم الآية.

5. **خوارزمية التكرار المتباعد الذكي (SM-2 Spaced Repetition):**
   - محرك تثبيت الحفظ لحساب فترات الاستذكار وعامل السهولة وشارة المهام اليومية المستحقة.

6. **المقارنة الحرة المباشرة بين أي آيتين (Custom Diff):**
   - محرك مقارنة لفظية حر يستخرج الكلمات الفارقة ونسبة التشابه المئوية آلياً.

7. **مولّد بطاقات الصور الدعوية للمشاركة (Card Infographic):**
   - توليد بطاقات كانفاس 1080x1350 مذهبة بدقة فائقة مع تحميل فوري PNG ونسخ للحافظة.

8. **المشغل الصوتي التناوبي الذكي:**
   - الاستماع التناوبي التلقائي بين الموضعين المتشابهين بأصوات كبار قراء العالم الإسلامي من مصحف KSU (الحصري، المنشاوي، الحذيفي، العفاسي، المعيقلي...).

9. **المنهجية السلفية والأمانة العلمية:**
   - تفسير السعدي، وابن كثير، والتفسير الميسر، وتوجيهات أمهات كتب المتشابهات (*البرهان* للكرماني، *درة التنزيل* للإسكافي، *ملاك التأويل* لابن الزبير، *هداية المرتاب* للسخاوي)، مع أحاديث الكتب الستة الصحيحة فقط.
